# MMG Tournament — Система Мак-Магона для турниров по Го

Программа для жеребьёвки и подведения итогов турниров по системе Мак-Магона с коэффициентами Бергера и Бухгольца.

## Установка

### Через `go install`

```bash
go install github.com/<username>/mmg-tournament@latest
```

> **Примечание:** замените `github.com/<username>/mmg-tournament` на фактический путь к репозиторию после его публикации.

### Из локального репозитория

```bash
git clone <repo-url>
cd mmg-tournament
go build -o mmg-tournament .
```

Скомпилированный бинарник `mmg-tournament` появится в текущей директории.

## Использование

### Первый тур (жеребьёвка)

```bash
mmg-tournament <base_filename> <total_rounds> <mcmahon_groups>
```

| Параметр | Описание |
|---|---|
| `base_filename` | Базовое имя CSV-файла (без расширения) |
| `total_rounds` | Общее количество туров в турнире |
| `mcmahon_groups` | Количество групп Мак-Магона |

**Пример:**

```bash
# Читает player_list.csv, создаёт player_list.001.csv
mmg-tournament player_list 5 4
```

### Последующие туры

После того как судьи внесли результаты предыдущего тура в CSV-файл:

```bash
mmg-tournament <base_filename> --round <round_num>
```

| Параметр | Описание |
|---|---|
| `base_filename` | Базовое имя CSV-файла |
| `--round <N>` | Номер тура, для которого производится жеребьёвка |

**Пример:**

```bash
# Читает player_list.001.csv с результатами, создаёт player_list.002.csv
mmg-tournament player_list --round 2
```

### Полный цикл турнира

```bash
# 1. Подготовка: создать player_list.csv с участниками
#    Формат: Имя,рейтинг
cat > player_list.csv <<EOF
Михаил Зайцев,2197
Ольга Копылова,2176
Алексей Лебедев,2040
# ... остальные участники
EOF

# 2. Жеребьёвка 1-го тура
mmg-tournament player_list 5 4

# 3. Судьи вносят результаты в player_list.001.csv
#    (заменяют ? на 1 или 0 в столбце результата)

# 4. Жеребьёвка 2-го тура
mmg-tournament player_list --round 2

# 5. Повторять шаги 3-4 для каждого тура
```

## Формат CSV-файлов

### Входной файл участников (`base_filename.csv`)

```csv
Имя_участника,рейтинг
```

### Файл жеребьёвки (`base_filename.XXX.csv`)

```csv
уникальный_номер,Имя,рейтинг,группа_Макмагон,очки,место,Бергер,Бухгольц,результат_1,результат_2,...
```

#### Столбцы

| # | Столбец | Описание |
|---|---|---|
| 1 | `уникальный_номер` | Присваивается программой (начиная с 1) |
| 2 | `Имя` | Имя участника |
| 3 | `рейтинг` | Рейтинг участника |
| 4 | `группа_Макмагон` | Номер группы (1 = сильнейшая) |
| 5 | `очки` | Текущая сумма MMS + заработанных очков |
| 6 | `место` | Порядковый номер в рейтинге |
| 7 | `Бергер` | Коэффициент Бергера |
| 8 | `Бухгольц` | Коэффициент Бухгольца |
| 9+ | `результат_N` | Результат тура N (формат `противник:итог` или `X`) |

#### Формат результата тура

| Значение | Описание |
|---|---|
| `N:1` | Победа над игроком N |
| `N:0` | Поражение от игрока N |
| `N:?` | Пара назначена, результат ещё не внесён |
| `X` | Пропуск тура (bye), засчитывается как победа |

## Система Мак-Магона

### Стартовые очки (MMS)

Участники делятся на группы по рейтингу. Последняя (слабейшая) группа получает 0 MMS, каждая следующая +1. Первая (сильнейшая) группа получает `кол-во_групп - 1` MMS.

### Жеребьёвка

- **1-й тур:** пары формируются внутри групп Мак-Магона
- **Последующие туры:** пары формируются по текущим очкам (игроки с одинаковым количеством очков сводятся вместе), с избеганием повторных встреч

### Коэффициенты

- **Бухгольц** — сумма очков всех соперников, с которыми играл участник
- **Бергер** — сумма очков соперников, у которых участник выиграл

Сортировка при равенстве очков: Бергер → Бухгольц → Рейтинг.
